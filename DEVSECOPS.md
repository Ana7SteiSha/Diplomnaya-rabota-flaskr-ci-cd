# DevSecOps Pipeline для Flaskr

## Обзор
Проект представляет собой веб-приложение на Flask с настроенным CI/CD пайплайном, включающим все этапы DevSecOps.

## Архитектура пайплайна

### Этап 1: CI/CD
- **Платформа:** GitHub Actions
- **Триггеры:** push в main, pull requests
- **Сборка:** Установка зависимостей, запуск тестов

### Этап 2: SAST (Static Application Security Testing)
- **Инструмент:** Bandit
- **Что проверяет:** Уязвимости в Python-коде (SQL-инъекции, XSS, hardcoded credentials)
- **Результат:** `bandit-report.json` (артефакт)

### Этап 3: DAST (Dynamic Application Security Testing)
- **Инструмент:** OWASP ZAP
- **Что проверяет:** Безопасность работающего приложения (HTTP-заголовки, уязвимости API)
- **Результат:** `dast-report.html` (артефакт)

### Этап 4: Security Checks
- **Инструменты:** Gitleaks + Trivy
- **Что проверяет:** 
  - Секреты в репозитории (Gitleaks)
  - Уязвимости в зависимостях (Trivy)
- **Результат:** `trivy-results.sarif` (артефакт)

### Этап 5: Security Gateway
- **Функция:** Блокировка релиза при критических уязвимостях
- **Дополнительно:** Комментирование в PR
- **Статус:** Готов к использованию

## Аналитика выбора инструментов

| Инструмент | Назначение | Альтернативы | Почему выбран |
|------------|------------|--------------|---------------|
| **Bandit** | SAST для Python | Semgrep, SonarQube | Легкий, встроен в экосистему Python |
| **OWASP ZAP** | DAST | Burp Suite, Nikto | Бесплатный, CI-дружественный |
| **Gitleaks** | Поиск секретов | TruffleHog | Простота настройки |
| **Trivy** | Сканирование зависимостей | Snyk, Dependabot | Бесплатный, все в одном |

## Зоны роста

1. **Интеграция с DefectDojo** — централизованное хранение отчетов
2. **Полноценное DAST** — активное сканирование с авторизацией
3. **Kubernetes Security** — проверка манифестов (checkov)
4. **Автоматическое обновление зависимостей** (Renovate)
5. **Настройка IAST** (Interactive AST) для анализа в рантайме

## Вывод
Пайплайн полностью соответствует требованиям DevSecOps и готов к использованию в production-среде.
